🚀 快速上手 (Quick Start)

WebChat2Local Studio 是一個專為本地開發者打造的 AI Coding IDE，透過瀏覽器擴充套件直接借力 ChatGPT / Gemini / DeepSeek 網頁版強大模型，並由本地交易引擎守護檔案安全。

三步驟開始使用：

  1. 步驟 1：開啟瀏覽器擴充套件

    在 Chrome 或 Edge 開啟 ChatGPT、Gemini 或 DeepSeek 網頁，擴充套件會自動建立 WebSocket 連線至本地 127.0.0.1:8765。

  2. 步驟 2：確認連線燈號

    Studio 頂部的 Provider 狀態燈會由灰色轉為綠色 🟢，表示 AI 模型通道已打通。

  3. 步驟 3：下達 Coding 指令

    在右側 Agent 側邊欄輸入指令，例如：「幫我閱讀 server/server.py 並新增一個 /health 測試」，AI 將自動呼叫工具並生成修改提案供您審查。

🛠️ Canonical Tools 規格全書

系統標準工具均採用 JSON Schema 定義與 SHA-256 Revision 交易鎖定機制，徹底告別脆弱的 XML 協議。

1. read_file (讀取檔案與產出 Revision)

// 輸入參數
{ "path": "src/main.py" }

// 輸出結構 (含 SHA-256 簽名)
{
  "path": "src/main.py",
  "revision": "sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "content": "print('hello world')\n"
}

2. edit_file (結構化文字替換與交易鎖定)

// 輸入參數 (要求嚴格唯一的 Exact Match)
{
  "path": "src/main.py",
  "revision": "sha256:e3b0c4...",
  "edits": [
    { "old_text": "print('hello world')", "new_text": "print('hello webchat2local')" }
  ]
}

// 錯誤代碼規格:
// • STALE_FILE: 檔案在讀取後已被外部修改
// • EDIT_MISMATCH: old_text 比對不符 (附帶 Normalized Match 建議)
// • AMBIGUOUS_MATCH: old_text 出現多次，需提供更多上下文

3. run_command (終端機命令執行)

// 輸入參數
{ "command": "pytest tests/ -v", "cwd": "." }

// 輸出格式
{ "exit_code": 0, "stdout": "36 passed in 2.5s", "stderr": "" }

🔌 本地 MCP (Model Context Protocol) Server 指引

內建官方 MCP Python SDK v2 實作，支援 STDIO 與 Streamable HTTP，可直接對接 Eclipse Theia、Claude Desktop、Cursor、Goose 等。

Eclipse Theia / Claude Desktop 設定檔 (mcp_connector.json)：

{
  "mcpServers": {
    "webchat2local": {
      "command": "python",
      "args": ["-m", "server.mcp.mcp_server"],
      "env": {
        "W2L_WORKSPACE": "${workspaceFolder}"
      }
    },
    "webchat2local-http": {
      "url": "http://127.0.0.1:8765/mcp"
    }
  }
}

🛡️ 權限策略與 Agent 模式

四級智慧權限控制，兼顧極速自動化與關鍵寫入安全。

權限層級適用操作行為說明
AUTOread_file, list_directory, grep_search唯讀查詢自動執行，無需人工確認
CONFIRMedit_file, create_file, delete_file, 危險指令生成 ChangeSet Diff 提案，待用戶審查批准
SESSION_ALLOWpytest, git status 等常規測試單次確認後本次 Session 自動放行
DENY路徑穿越 (../)、UNC 路徑、機密檔案 (.env)系統沙盒強制阻擋

⚙️ 系統 Prompt 與 Rules 自訂規範

在專案根目錄下建立 .webchat2local/rules/ 目錄，撰寫 .md 規則檔案，Agent 在每次對話時會自動加載並嚴格遵循。

// .webchat2local/rules/coding-style.md 範例
# 專案編程風格規範
1. 所有 Python 函式必須包含 Type Hints。
2. 避免引入非必要的第三方套件。
3. 修改現有程式碼時，保留既有的註解與函式簽名。

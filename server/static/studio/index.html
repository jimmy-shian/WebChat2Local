說明書與規格指引 (Docs & Specs)

5分鐘指引

1. 連線 ChatGPT / Gemini / DeepSeek 擴充套件。

2. 開啟 Studio 並確認右下角綠燈。

3. 於右側對話框下達第一個 AI Coding 指令，例如「幫我建立一個 index.html」。

工具規範 (Tool Specs)

支援 7 款 Canonical Tools：

  • read_file
  • edit_file
  • create_file
  • delete_file
  • list_directory
  • grep_search
  • run_command

本地 MCP Server 指引

如何在 Eclipse Theia、Cursor、Claude Desktop 中設定 STDIO (python -m server.mcp.mcp_server) 或 Streamable HTTP (http://127.0.0.1:8765/mcp)。

權限與 Agent 模式

支援 ASK, PLAN, CODE, DEBUG, AGENT 模式。

4 級權限策略：AUTO, CONFIRM, SESSION_ALLOW, DENY。

系統 Prompt 與 Rules

在專案中建立 .webchat2local/rules/ 自訂規則，系統會自動載入。
